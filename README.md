# Galeris

Editor 3D para una galería de la Facultad de Artes.

## Requisitos

- Godot **4.7**, renderer **Forward Plus**.

La versión exacta del proyecto está declarada en `project.godot` mediante
`config/features=PackedStringArray("4.7", "Forward Plus")`.

## Entrega A

- `AppMode` es el único origen del modo actual.
- El JSON local es la fuente de verdad del proyecto.
- El contrato persistido está documentado en
  [`docs/CONTRATO_GUARDADO.md`](docs/CONTRATO_GUARDADO.md).
- La carga que instancia nodos pertenece a la Entrega B.
